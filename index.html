Costs

Aplicação React que permite cadastrar, editar e excluir despesas com valor, categoria e descrição. Utiliza JSON Server para simular um backend RESTful local, com persistência de dados via requisições HTTP (CRUD). Checklist de Viagem Inteligente

Projeto em Next.js que cria checklists de viagem personalizados com base no clima da cidade, utilizando a API do OpenWeatherMap. Exibe dados como temperatura e vento, e sugere itens conforme o clima. O usuário pode marcar itens, adicionar novos e salvar múltiplos checklists. Dados são persistidos no localStorage. Utiliza React Hooks, CSS Modules, Lucide React e React Icons.
